# Space Grotesk

Regular and Bold static TTF files for the leadership PNG export, licensed under the included SIL Open Font License (`OFL.txt`).

Source: https://github.com/floriankarsten/space-grotesk/tree/03507d024a01282884232081fc6011c09ff4e849/fonts/ttf/static

These files are bundled locally so generating a public graphic does not contact a font service or depend on installed system fonts.
